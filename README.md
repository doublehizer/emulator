# Эмулятор командной строки UNIX

Практическая работа № 1 по дисциплине «Конфигурационное управление»,
вариант 12.

## Общее описание

Графическое приложение (GUI на `tkinter`), которое имитирует работу
командной строки UNIX-подобной ОС. Пользователь вводит команды в строку
ввода внизу окна, а команды и их результаты появляются в поле вывода.

Текущий этап — **этап 3 (VFS)**. Команды `ls` и `cd` пока
являются заглушками и выводят своё имя и аргументы.

Возможности:

- окно с полем вывода и строкой ввода;
- имя VFS в заголовке окна (имя файла VFS без расширения,
  по умолчанию — `default`);
- парсер, который корректно обрабатывает аргументы в кавычках
  (`cd "My Documents"` — один аргумент);
- сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка;
- команды-заглушки `ls`, `cd` и команда `exit`;
- параметры командной строки `--vfs` и `--script`;
- отладочный вывод всех параметров при запуске (в терминал и в окно);
- стартовый скрипт, который останавливается на первой ошибке;
- виртуальная файловая система (VFS) из CSV-файла, хранится в памяти;
- служебная команда `vfs-info` (имя VFS и хеш SHA-256).

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs ПУТЬ` | путь к физическому расположению VFS; имя файла без расширения становится именем VFS |
| `--script ПУТЬ` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

Неизвестный параметр — ошибка: эмулятор выводит подсказку и не запускается.

## Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку. После
открытия окна команды выполняются по очереди, как будто их вводит
пользователь: в окне видны и команда (`$ ls`), и её результат.

- Пустые строки пропускаются.
- На **первой ошибке** выполнение останавливается, выводится сообщение
  `Скрипт остановлен: ошибка в строке N.` Дальше можно вводить команды
  вручную.
- Если файл скрипта не найден или не читается, выводится ошибка.

## Формат VFS

VFS — это CSV-файл с заголовком `path,type,content`:

| Колонка | Значение |
|---|---|
| `path` | полный путь от корня: `/home/user/notes.txt` |
| `type` | `dir` — каталог, `file` — файл |
| `content` | содержимое файла в base64 (у каталога — пусто) |

Вложенность задаётся путём: `/home/user` лежит внутри `/home`.
Каталог нужно описать раньше, чем то, что в нём лежит.

```
path,type,content
/home,dir,
/home/user,dir,
/home/user/hello.txt,file,aGVsbG8=
```

VFS целиком загружается в память, файл на диске не изменяется.
Если файл не найден или формат неверный, выводится ошибка
загрузки (с номером строки), и эмулятор работает с пустой
VFS `default`.

## Команды

| Команда | Описание | Ошибки |
|---|---|---|
| `ls [аргументы...]` | Заглушка: выводит `ls` и список аргументов | — |
| `cd [каталог]` | Заглушка: выводит `cd` и список аргументов | больше одного аргумента |
| `exit` | Закрывает эмулятор | переданы аргументы |
| `vfs-info` | Имя VFS, хеш SHA-256 файла VFS, число каталогов и файлов | переданы аргументы |

Любая другая команда даёт ошибку `команда не найдена`.

## Структура проекта

```
src/emulator/
    __main__.py   запуск через python3 -m emulator
    main.py       точка входа: параметры, Shell, окно, скрипт
    config.py     параметры командной строки и отладочный вывод
    script.py     чтение и выполнение стартового скрипта
    gui.py        окно tkinter (класс EmulatorWindow)
    shell.py      ядро: класс Shell, метод execute()
    commands.py   функции команд и словарь COMMANDS
    parser.py     разбор строки на команду и аргументы
    vfs.py        VFS в памяти и загрузка из CSV
    errors.py     классы ошибок эмулятора
tests/
    test_*.py     автотесты (unittest)
    scripts/      стартовые скрипты эмулятора
    stage2/       скрипты ОС для проверки параметров (этап 2)
    stage3/       скрипты ОС для проверки разных VFS (этап 3)
    vfs/          файлы VFS
run.sh            скрипт запуска
```

## Сборка и запуск

Нужен Python 3.9+ с `tkinter`. Сторонние библиотеки не нужны,
сборка не требуется. На macOS рекомендуется Python из Homebrew
(`brew install python-tk`): встроенный системный Tk 8.5 может
показывать пустые окна.

Запуск эмулятора:

```sh
./run.sh
./run.sh --vfs tests/vfs/demo.csv --script tests/scripts/ok.txt
```

Запуск автотестов:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Скрипты ОС для проверки параметров (этап 2):

| Скрипт | Что проверяет |
|---|---|
| `tests/stage2/no_args.sh` | запуск без параметров |
| `tests/stage2/vfs_only.sh` | только `--vfs` (имя VFS в заголовке) |
| `tests/stage2/script_only.sh` | только `--script`, скрипт без ошибок |
| `tests/stage2/all_params.sh` | оба параметра |
| `tests/stage2/script_error.sh` | остановка скрипта на ошибке в строке 3 |
| `tests/stage2/script_missing.sh` | несуществующий скрипт |
| `tests/stage2/bad_option.sh` | неизвестный параметр |
| `tests/stage2/run_all.sh` | все проверки по очереди |

Скрипты ОС для проверки VFS (этап 3):

| Скрипт | Что проверяет |
|---|---|
| `tests/stage3/minimal.sh` | минимальная VFS (`minimal.csv`, пустой корень) |
| `tests/stage3/files.sh` | несколько файлов (`files.csv`, есть двоичный) |
| `tests/stage3/nested.sh` | 4 уровня каталогов и файлов (`demo.csv`) |
| `tests/stage3/not_found.sh` | файла VFS нет |
| `tests/stage3/bad_format.sh` | неверный заголовок, не base64, нет родителя |
| `tests/stage3/all_commands.sh` | все команды этапов 1–3 (`stage3.txt`) |
| `tests/stage3/run_all.sh` | все проверки по очереди |

## Примеры использования

Запуск со скриптом, в котором ошибка:

```sh
./run.sh --vfs tests/vfs/demo.csv --script tests/scripts/error.txt
```

Вывод в окне:

```
Эмулятор запущен. VFS: demo. Для выхода введите exit.
Параметры запуска:
  vfs = tests/vfs/demo.csv
  script = tests/scripts/error.txt
--- Выполнение стартового скрипта: tests/scripts/error.txt ---
$ ls /home
ls ['/home']
$ cd "My Documents"
cd ['My Documents']
$ foo
Ошибка: foo: команда не найдена
Скрипт остановлен: ошибка в строке 3.
```

Ручной ввод:

```
$ cd a b
Ошибка: cd: слишком много аргументов
$ cd "abc
Ошибка: синтаксическая ошибка: не закрыта кавычка
$ exit
```
